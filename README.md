# SyncMate ⚡
> **Your Autonomous Personal Secretary & Lifestyle OS**

SyncMate is an intelligent, context-aware digital assistant designed to build daily consistency. It dynamically structures your daily 24-hour timeline around unmovable spiritual prayer anchors, long-term learning goals, local weather predictions, and real-time health habits.

## ✨ Key Features

### 🧠 Autonomous AI Secretary
- **Clarifying Intelligence**: SyncMate never assumes vague input. If you mention a multi-step project, it asks proactive, practical questions to break down the task correctly.
- **Self-Healing Daily Timeline**: Leftover tasks automatically re-cluster into open focus slots on subsequent days without overwhelming red "OVERDUE" alerts.
- **Voice & Chat Interface**: Talk or type directly to your assistant using built-in speech recognition and synthesis.

### 🌙 Spiritual Alignment & Context Engine
- **Unbreakable Prayer Anchors**: Automatically fetches and locks the 5 daily prayer times (Fajr, Dhuhr, Asr, Maghrib, Isha) onto your 24-hour timeline.
- **Mosque Jamat Custom Overrides**: Manually adjust individual prayer block times to match your local mosque schedule.
- **Dual Calendar**: Displays both Gregorian/Solar and Hijri dates simultaneously.
- **Emotionally Contextual Insights**: Completing a prayer triggers authentic Quranic Ayahs and Ahadith dynamically routed based on your recent chat mood (e.g., hardship, stress, gratitude) fetched directly from verified, open-source APIs.

### 🎯 Long-Term Project & Course Decomposition
- **Paced Learning**: Automatically breaks complex courses or projects into bite-sized 30–45 minute focus modules.
- **Burnout Protection**: Enforces multi-day pacing strategies (Balanced, Steady, Intensive) to prevent dumping entire multi-week courses into a single day.

### 🏋️ Health, Fitness & Micro-Habit Engine
- **AI Fitness Coach**: Generates zero-equipment, bodyweight routines tailored to custom physical goals (weight loss, posture, height stretching) and auto-slots them into your timeline gaps.
- **Streak Protection**: Tracks daily micro-habits (Plank, Hydration, Eye Relief) and fires warning alerts before active streaks decay at the end of the day.
- **Interactive Timers & Chimes**: Built-in audio chimes and countdown timers for active rest breaks.

### 📍 Dual Geolocation & Weather Integration
- **High-Accuracy GPS & IP Fallback**: Uses browser GPS with automatic IP geolocation fallback and manual city search capabilities.
- **Live Weather Integration**: Real-time local forecasts (via Open-Meteo) automatically influence task suggestions (e.g., moving outdoor events indoors during heavy rain).

## 🛠️ Tech Stack

- **Frontend**: HTML5, Modern JavaScript (ES6+), Tailwind CSS
- **Backend & Database**: Firebase Authentication, Cloud Firestore
- **AI Integration**: Gemini API (Structured JSON Mode)
- **APIs**: Aladhan Prayer Times API, Open-Meteo Weather API, Al Quran Cloud API
- **Hosting**: Cloudflare Pages (Continuous Deployment via GitHub)
